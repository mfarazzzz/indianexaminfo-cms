`indianexaminfo-frontend/next.config.ts:21-24` and `indianexaminfo-cms/vite.config.ts:30-33`
both do `const dirty = run("git status --porcelain"); if (dirty) sync = "dirty"`. `git status
--porcelain` lists **untracked** files too, and both repos leave qa/build transcripts untracked.
So "dirty" here is not evidence that deployed code differs from the commit; it is evidence the
stamp function cannot tell untracked files from modified ones. Adding `--untracked-files=no` (and
narrowing the label "built with uncommitted changes" in `src/config/buildInfo.ts:38`) would make
the flag mean what it says.
